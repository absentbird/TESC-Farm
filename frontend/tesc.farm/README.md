# Vue 3 + TypeScript + Vite + Tailwind CSS

This site uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

To learn more about tailwind classes and options visit [tailwindcss.com](https://tailwindcss.com/)

Learn more about the recommended Project Setup and IDE Support in the [Vue Docs TypeScript Guide](https://vuejs.org/guide/typescript/overview.html#project-setup).

## Running
To launch a development version of the site on your local system run `npm run dev`

## Compiling
To compile a set of static files to be hosted on the server run `npm run build`
